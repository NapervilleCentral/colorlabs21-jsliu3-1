Final Collage Project readme:
I took a picture from a really famous gd level and I first mirrored the right side of the image to the left side of the image to create a mirroring effect, I blended the image with another really goofy gd level picture by taking the average of the respective pixels from both images, I created a dramatic grayscale using the grayscale and posterizing method using black, dark gray, gray, and white (which I accidentally found), I thought it would be a good idea to make the picture look really bright (to resemble the flashbang effect) by raising the rgb values of each pixel by like 165, I recursed the image to the top left corner while alternating between inversed and regular images (by decreasing the length of the image each time until one length goes below 25 or something), I red spammed the image by increasing the red value of each pixel a bunch, I deepfryed/dramaticized the image by increasing high rgb value pixels and decreasing low rgb value pixels (which looks pretty cool), and I yellow spammed the image by increasing the red and green values of each pixel in the image.
